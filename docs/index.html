The problem

“Similar” is not “supports.”

Grounding a scientific statement means pointing to a real sentence in the literature that genuinely backs it — the task behind citation recommendation, claim attribution and RAG faithfulness. A sentence can be lexically or semantically similar to a claim without supporting it. Cheap similarity scores let those false positives through; the fix the field has converged on is a second, sharper pass.

70%

Noise in first-pass

Bi-encoder cosine similarity scores a passage in isolation. It rewards shared vocabulary and topic — not whether the evidence entails the claim.

+17 pp

Rerank gain

Adding a cross-encoder after first-pass retrieval is the single largest quality jump reported: +17.2pp MRR@3, +12.1pp Recall@5 over unreranked hybrid retrieval.

4-stage

Field consensus

Recent systems converge on one shape: retrieve → fuse → cross-encoder rerank → entailment check. PubGround implements all four.

The system

Hybrid recall, one cross-encoder at the core.

Keyword and dense retrieval are fused, then the MedCPT cross-encoder decides — first over abstracts, then over sentences. An optional judge says whether each cited abstract actually supports the claim. A language-model re-scoring stage was benchmarked and removed: on top of the reranker it added at most 0.007 nDCG@10 while costing ~20 extra LLM calls per query.

Benchmark · SciFact · SciFact-Open · HealthVer

Measured as it runs, at two scales.

Every PubGround number comes from the package itself. Three public datasets: SciFact (300 claims, 5,183 abstracts), SciFact-Open (279 claims against 500,000 abstracts) and HealthVer (230 COVID health claims), against four embedders, five rerankers, OpenScholar and two published verifiers on identical inputs, with 95% bootstrap intervals over claims. Run it yourself: pip install "pubground[bench]".

9×

the throughput of Qwen3-Reranker-4B, with no significant nDCG@10 gap on SciFact (0.792 vs 0.801, difference 95% CI −0.032 to +0.014; 345 vs 38 pairs/s on one H100).

At 500K abstracts the larger reranker pulls ahead (0.806 vs 0.750, significant). PubGround beats OpenScholar's retrieval pipeline by 0.10 nDCG@10 on both corpora. Hybrid recall lifts Recall@100 over BM25 on both corpora; LLM query expansion adds nothing on top. The PubGround judge beats every verifier not trained in-domain — but a model trained on HealthVer still wins there.

Agent-native

The whole engine, as an MCP server.

Built on the official MCP SDK (FastMCP), PubGround exposes its grounding capability as two tools any MCP client — Claude Code, Claude Desktop, other agents — can call. Pipeline stdout is redirected to stderr so the stdio JSON-RPC stream stays clean.

tool

find_citations

End-to-end grounding: sentence → top_k cited evidence sentences with scores, journals and formatted citations (MLA / APA / Nature); verify=True adds a verdict per abstract.

tool

pubmed_search

The low-level building block — a raw query returns matching PMIDs, for agents that want to drive the pipeline themselves.

register with Claude Code 
# one line — the engine becomes a tool
claude mcp add citation-matcher \
  -- python mcp_servers/citation_server.py

# then, from any MCP client:
find_citations(
  sentence="Statins reduce cardiovascular events.",
  top_k=6,
  citation_format="apa",
  verify=True,
)

Toggles via env: CITATION_USE_RERANKER=0 disables reranking · PUBMED_EMAIL sets NCBI identity.
