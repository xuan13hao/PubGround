The problem

“Similar” is not “supports.”

Grounding a scientific statement means pointing to a real sentence in the literature that genuinely backs it — the task behind citation recommendation, claim attribution, and RAG faithfulness. The trap: a sentence can be lexically or semantically similar to your claim while not actually supporting it. Cheap similarity scores let those false positives through. The fix the field has converged on is a second, sharper pass.

70%

Noise in first-pass

Bi-encoder cosine similarity scores a passage in isolation. It rewards shared vocabulary and topic — not whether the evidence entails the claim.

+17pp

Rerank gain

Adding a cross-encoder after first-pass retrieval is the single largest quality jump reported: +17.2pp MRR@3, +12.1pp Recall@5 over unreranked hybrid retrieval.

4-stage

Field consensus

2024–25 SOTA systems collapse to one shape: retrieve → fuse → cross-encoder rerank → entailment-check. This project adopts the rerank stage first.

The system

Six stages, one new linchpin.

The original engine was a sound multi-stage design using 2020-era hand-tuned similarity. Stage 4.5 replaces the weak middle with the field's highest-leverage component — the multi-signal score is demoted to a cheap shortlist feeding the cross-encoder. An LLM re-verification stage was benchmarked and removed: on top of the reranker it added at most 0.007 nDCG@10 while costing ~20 extra LLM calls per query.

Benchmark · SciFact · SciFact-Open · HealthVer

Measured against the field, at two scales.

Three public datasets: SciFact (300 claims, 5,183 abstracts), SciFact-Open (279 claims against 500,000 abstracts) and HealthVer (230 COVID health claims). Every system — PubGround's components, four open-source rerankers, four embedders, two published verifiers — sees the same claims, candidate lists and metrics, with 95% bootstrap intervals over claims.

1/18 of the wall-clock time of Qwen3-Reranker-4B, with no significant nDCG@10 gap on SciFact
(0.792 vs 0.802, difference 95% CI −0.013 to 0.032; 59 s vs 1,062 s for 40,634 unique pairs — BM25 ∪ hybrid top-100 — single run incl. model loading)

At 500K abstracts the larger reranker pulls ahead (0.806 vs 0.750, significant). Fusing BM25 with MedCPT dense retrieval lifts Recall@100 over BM25 on both corpora (best first stage at 500K abstracts) and lifts every reranker tested; LLM query expansion matches it but adds nothing on top. A zero-shot LLM judge beats every verifier not trained in-domain — but a supervised model trained on HealthVer still wins there.

Agent-native

The whole engine, as an MCP server.

Rebuilt on the official MCP SDK (FastMCP), the system exposes its grounding capability as two tools any MCP client — Claude Code, Claude Desktop, other agents — can call. Pipeline stdout is redirected to stderr so the stdio JSON-RPC stream stays clean.

tool

find_citations

End-to-end grounding. sentence → top_k cited evidence sentences with scores, journals and formatted citations (MLA / APA / Nature).

tool

pubmed_search

The low-level building block — a raw query returns matching PMIDs, for agents that want to drive the pipeline themselves.

register with claude code 
# one line — the engine becomes a tool
claude mcp add citation-matcher \
  -- python mcp_servers/citation_server.py

# then, from any MCP client:
find_citations(
  sentence="Statins reduce cardiovascular events.",
  top_k=6,
  citation_format="apa",
)

Toggles via env: CITATION_USE_RERANKER=0 disables reranking · PUBMED_EMAIL sets NCBI identity.

What's next

Closing the loop to full attribution.

The rerank stage and MCP server ship now. Three stages remain to match the full field-standard pipeline — each already scoped against the research above.

recall

Dense retrieval + RRF

Add MedCPT's query encoder alongside keyword search and fuse with Reciprocal Rank Fusion. Benchmarked: Recall@100 rises from 0.873 / 0.864 (BM25) to 0.973 / 0.964 — the best first stage at 500K abstracts — and every reranker tested gains. Next to ship.

truth

NLI entailment verdict

Upgrade “similar” to SUPPORTS / REFUTES / NEI with rationale spans. Benchmarked: a zero-shot LLM judge beats VeriSci and zero-shot MultiVerS on all three datasets; it needs a less strict prompt for HealthVer-style “partial support”.

depth

PMC full text

Wire the BioC API for open-access full text and escalate from abstract to passage when the abstract alone is insufficient.
